# Подключение Claude к MeetOwl

Что получится: вы пишете Claude в обычном чате («покажи мой день», «добавь встречу с Анной в четверг в 15:00», «найди клиента Nordwind и передвинь сделку на следующий этап»), а он выполняет это в MeetOwl от вашего имени. Так же устроено подключение Notion.

Нужно: боевая версия на `https://…` (в `APP_URL`), пространство с планом **Pro** (у вас он выдан через `PRO_OWNER_EMAILS`) и вы как участник пространства (не гость и не клиент).

## 1. Обновите боевую версию

В базу добавляются новые таблицы (`0010_oauth_mcp`). Vercel применит их сам при сборке (`vercel-build` запускает `prisma migrate deploy`). Дополнительных переменных не нужно: адрес берётся из `APP_URL`.

Проверка: откройте `<адрес>/.well-known/oauth-authorization-server`. Должен открыться текст с `"issuer"` и вашим адресом.

## 2. Подключите в Claude

1. В Claude (сайт или приложение) откройте **Settings → Connectors → Add custom connector**.
2. Имя: `MeetOwl`. Адрес: `<адрес>/api/mcp` (его же можно скопировать в MeetOwl: **Settings → Developers → Connect Claude**).
3. Нажмите **Add**, затем **Connect**. Откроется окно MeetOwl:
   - войдите по почте, если просят;
   - выберите пространство;
   - выберите доступ: **Читать и менять** или **Только читать**;
   - нажмите **Разрешить**.
4. В новом чате включите коннектор MeetOwl (кнопка «+» → Connectors) и попросите, например: «Что у меня сегодня в MeetOwl?».

Если окно показывает «Это приложение не от Anthropic», остановитесь: значит, ссылка пришла не из Claude. Для Claude адрес возврата `claude.ai`.

## 3. Что Claude умеет

- **Читать:** проекты и карту проекта, задачи и документы, поиск, комментарии, календарь, «Мой день», контакты, компании, сделки, CRM-активности.
- **Менять** (только при доступе «Читать и менять»): создавать и править задачи, эпики, документы и встречи, комментировать, вносить время, архивировать узел (его можно вернуть в приложении), создавать и править контакты, компании и сделки, переводить сделку по этапам, записывать звонки и заметки.
- Он видит и меняет только то, что доступно вам. Все изменения идут в журнал действий как обычные.
- Инструменты Claude принимают и отдают время по UTC (ISO 8601 с `Z`). Календарь в MeetOwl показывает его в вашем часовом поясе (Настройки → Аккаунт). Если просите «в 18:00», уточните, по какому поясу.

## 4. Отключить

**Settings → Developers → Connect Claude → Connected applications → Disconnect.** Доступ закрывается сразу: токены перестают работать. Владельцы и администраторы видят и могут отключить подключения всех участников. Подключение само закроется, если вас убрали из пространства или план упал ниже Pro.

## 5. Claude Code и другие программы

Claude Code открывает то же окно входа:

```bash
claude mcp add --transport http meetowl <адрес>/api/mcp
```

Затем в Claude Code выполните `/mcp` и выберите **Authenticate**. Программа, которая не умеет входить через браузер, может использовать личный токен (Settings → Developers → Access tokens) в заголовке `Authorization: Bearer …`.

## Безопасность

- Вход по OAuth 2.1 с PKCE; код одноразовый и живёт 5 минут; токен доступа живёт час, обновляется токеном, который меняется при каждом использовании. Повторное использование старого закрывает подключение целиком.
- Согласие даёт только вошедший человек со страницы MeetOwl (проверяются Origin и сессия). Адрес возврата проверяется точным совпадением с зарегистрированным.
- Тексты задач, заметок и заявок с сайта пишут люди и посторонние. Claude предупреждён, что это данные, а не команды, но вам стоит подключать «Читать и менять» только там, где вы готовы это принять; для просмотра хватит «Только читать».
- Секреты (токены) в чат Claude и в этот чат не вставляйте.

## Если не получается

- **«Не удалось подключиться» сразу:** проверьте, что адрес начинается с `https://` и открывается в браузере; что `APP_URL` в Vercel совпадает с ним без слеша в конце.
- **В окне «Ни одно пространство нельзя подключить»:** нужен план Pro и роль выше гостя.
- **Claude подключился, но инструментов нет:** при доступе «Только читать» изменяющие инструменты скрыты намеренно. Отключите и подключите заново с «Читать и менять».
- **Подключение вдруг пропало:** его закрыл повторно использованный токен (например, второе окно обновило токен параллельно) или вас убрали из пространства. Подключите заново: это один клик.
