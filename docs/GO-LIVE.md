# Боевая версия на Vercel: вход по e-mail и Pro для вас

Это инструкция для **настоящей** версии, где люди регистрируются по ссылке из письма. Публичное демо (`DEPLOY.md`) остаётся отдельно: в нём все делят одни данные и нельзя хранить ничего личного.

**Почему отдельный проект.** Боевая версия получает свою базу и свои секреты. Данные настоящих пользователей никогда не смешиваются с демо, в которое может зайти кто угодно.

## 0. Что вы получите

- Регистрация и вход по ссылке из письма (Magic Link) для любого человека.
- План **Pro** для всех рабочих пространств, где владелец это адрес из списка `PRO_OWNER_EMAILS` (ваш), без оплаты через Stripe.
- Письма уходят с вашего Gmail (до ~500 в сутки), пока у вас нет своего домена.
- Адрес вида `https://<имя>.vercel.app`.

## 1. База данных (Neon), новая

1. На neon.tech нажмите **New Project**, имя `meetowl-prod`, регион **Frankfurt** (ближе к пользователям из ЕС).
2. **Connect** → выключите **Connection pooling** → скопируйте строку `postgresql://…?sslmode=require`. Это `DATABASE_URL`.

## 2. Пароль приложения Gmail

Обычный пароль Gmail для этого не подойдёт.

1. Откройте myaccount.google.com → **Безопасность** → включите **двухэтапную аутентификацию**.
2. Откройте myaccount.google.com/apppasswords, назовите пароль `MeetOwl`, нажмите **Создать**.
3. Скопируйте 16 букв (пробелы не нужны). Это `SMTP_PASS`. Показывается один раз.

## 3. Проект на Vercel

1. vercel.com → **Add New → Project** → тот же репозиторий → **Project Name**: например `meetowl-app` (тогда адрес будет `https://meetowl-app.vercel.app`; если имя занято, Vercel добавит суффикс, настоящий адрес смотрите в **Settings → Domains**).
2. В **Environment Variables** добавьте:

| Имя | Значение |
| --- | --- |
| `DATABASE_URL` | строка из шага 1 |
| `AUTH_SECRET` | новая случайная строка (команда ниже) |
| `SECRETS_KEY` | ещё одна новая случайная строка |
| `AUTH_TRUST_HOST` | `true` |
| `AUTH_URL` | `https://<ваш-адрес>.vercel.app` (без слеша в конце) |
| `APP_URL` | то же самое |
| `MAIL_FROM` | `MeetOwl <ваш@gmail.com>` |
| `SMTP_HOST` | `smtp.gmail.com` |
| `SMTP_PORT` | `465` |
| `SMTP_USER` | `ваш@gmail.com` |
| `SMTP_PASS` | 16 букв из шага 2 |
| `PRO_OWNER_EMAILS` | `ваш@gmail.com` (несколько адресов через запятую) |
| `SUPERADMIN_EMAILS` | `ваш@gmail.com` (владелец платформы: только эти адреса открывают «Администрирование платформы») |
| `LEGAL_OPERATOR_NAME` | ваше имя или название компании |
| `LEGAL_CONTACT_EMAIL` | адрес, на который писать по вопросам данных |

Не добавляйте `DEMO_MODE`: в боевой версии кнопки демо быть не должно.

```
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

3. **Deploy**. Сборка применит миграции базы.

## 4. Первый вход

1. Откройте адрес сайта → введите **ваш** адрес из `PRO_OWNER_EMAILS` → поставьте галочку согласия → **Send magic link**.
2. Письмо придёт на Gmail (проверьте «Спам» при первом разе). Нажмите ссылку, затем кнопку **Sign in** на открывшейся странице.
3. Создайте рабочее пространство. **Settings → Billing** покажет **Pro** и подпись, что план выдан администратором.

Если письмо не приходит: проверьте `SMTP_*` и что включена двухэтапная аутентификация; в Vercel **Logs** будет строка с ошибкой отправки.

## 5. Фоновые задачи (Inngest), рекомендуется

Без них вход работает, но не работают письма-уведомления, напоминания и ночные пересчёты (здоровье проектов, очистка).

1. На inngest.com создайте аккаунт и приложение.
2. Скопируйте **Event Key** и **Signing Key**.
3. В Vercel добавьте `INNGEST_EVENT_KEY`, `INNGEST_SIGNING_KEY` и `JOBS_MODE` = `inngest`, затем **Redeploy**.
4. В Inngest синхронизируйте приложение с адресом `https://<ваш-адрес>/api/inngest`.

## 6. Как защищена регистрация

- **Ссылка из письма одноразовая, живёт 15 минут** и открывает страницу с кнопкой: почтовые антивирусы, которые «прокликивают» все ссылки, её не сжигают.
- **Согласие с условиями** проверяется на сервере: без него письмо не отправляется.
- **Лимиты:** 5 писем на адрес и 30 на IP за 15 минут; в сутки 20 писем на IP, 10 на один почтовый ящик и 300 на весь сайт (`MAIL_DAILY_LIMIT`), чтобы не исчерпать квоту Gmail. Хранятся только хэши.
- Ответ формы не показывает, есть ли такой аккаунт.
- Каждый человек видит только свои рабочие пространства; пользователь может сам скачать данные и удалить аккаунт (Настройки → Аккаунт).

## 7. Перед тем как звать других людей

- [ ] Юрист прочитал **политику конфиденциальности** и **условия** (`/legal/privacy`, `/legal/terms`): это черновики.
- [ ] Бесплатная база Neon: 0,5 ГБ и короткая история копий. Для платящих клиентов нужен платный план.
- [ ] Gmail рассчитан на небольшой поток. Для роста подключите свой домен и Resend (`RESEND_API_KEY`, `MAIL_FROM` на своём домене).
- [ ] Вложения не работают без хранилища (`S3_*`), AI без `ANTHROPIC_API_KEY`, Stripe без своих ключей.
- [ ] Остальное: `docs/PRODUCTION.md`.

## 8. Что менять потом

- **Убрать Pro у адреса:** уберите его из `PRO_OWNER_EMAILS` и поменяйте план рабочего пространства вручную в базе: список только выдаёт, но не отбирает.
- **Свой домен:** Vercel → **Settings → Domains**, затем обновите `AUTH_URL` и `APP_URL` и сделайте **Redeploy**.
