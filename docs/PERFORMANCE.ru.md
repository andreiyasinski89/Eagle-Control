# Если приложение отвечает медленно

Нажали кнопку и ждёте несколько секунд? Почти всегда причина одна из трёх. Проверьте по порядку.

## 1. Сервер и база далеко друг от друга (самое частое)

Приложение работает на Vercel, данные лежат в Neon. Если они в разных частях света, каждое обращение к базе идёт через океан (около 0,1 секунды), а на одной странице таких обращений бывает до десяти.

Как проверить и исправить:
1. neon.tech → ваш проект → **Settings → Region**. Запомните регион (Франкфурт, США…).
2. Vercel → проект `meetowl-app` → **Settings → Functions → Function Region**. Выберите тот же регион, что у базы (для Франкфурта это `fra1`).
3. Сделайте **Redeploy** (Deployments → три точки у последнего → Redeploy).

Если база в США, а пользователи в Европе, лучше перенести базу во Франкфурт (новый проект Neon в нужном регионе и перенос данных; позовите меня, помогу).

## 2. Бесплатная база «засыпает»

Бесплатный Neon усыпляет базу после 5 минут без запросов. Первое нажатие после паузы ждёт 1–3 секунды, пока база проснётся.

Бесплатное решение: сервис вроде UptimeRobot. Создайте монитор «HTTP(s)» на адрес `https://ВАШ-САЙТ/api/health` с проверкой раз в 5 минут. Эта страница сама обращается к базе и не даёт ей уснуть. Платное решение: платный план Neon (база не засыпает).

## 3. Запросы в базу идут по одному

В адресе базы (`DATABASE_URL` в Vercel) стоит `connection_limit=1`. Это значит, что запросы, которые могли бы идти одновременно, стоят в очереди. Для Neon с адресом через пулер (в хосте есть `-pooler`) безопасно поставить `connection_limit=5`:

`...?sslmode=require&pgbouncer=true&connection_limit=5`

После изменения переменной сделайте Redeploy.

## Как увидеть, что именно медленное

В Vercel → Settings → Environment Variables добавьте переменную `DB_SLOW_MS` со значением `300` и сделайте Redeploy. Тогда в журналах (Vercel → Logs) появятся строки `[db] 412 ms SELECT ...` для каждого запроса, который занял 0,3 секунды и дольше. Пришлите мне несколько таких строк, и я найду, что ускорять. Когда разберёмся, переменную можно удалить.
