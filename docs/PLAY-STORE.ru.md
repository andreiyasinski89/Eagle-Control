# MLM CRM в Google Play: пошаговая инструкция

**Как это устроено.** Приложение для Android — это наш сайт mlmcrm.app, открытый на весь экран без адресной строки (Trusted Web Activity). Отдельно писать приложение не нужно: всё, что мы меняем на сайте, сразу появляется и в приложении, без обновлений в Play Market.

**Что уже сделано в коде (0.67.0):** иконки и ярлыки (долгое нажатие на иконку: «Мой день», «Касания», «Люди», «Календарь»), адрес `/.well-known/assetlinks.json` для связи сайта и приложения, режим приложения без кнопок оплаты (правила Google), публичная страница удаления аккаунта, тексты карточки на 4 языках и обложка (папка `docs/play-store/`).

**Никогда никому не присылайте** (и мне в чат тоже): файл ключа подписи (`.keystore`), его пароли, пароль от Play Console. Отпечатки ключа (SHA-256) — не секрет, их можно.

---

## Шаг 1. Аккаунт разработчика Google Play (один раз, 25 $)

1. Откройте play.google.com/console, войдите своим Google-аккаунтом.
2. Тип аккаунта:
   - **Личный (Personal)** — быстрее. Но новое приложение с личного аккаунта перед выходом обязано пройти **закрытое тестирование: не меньше 12 тестировщиков 14 дней подряд**. Для вас это нормально: тестировщики — ваша команда.
   - **Организация (Organization)** — без правила 12 тестировщиков, но нужен номер **D-U-N-S** на ваше грузинское ИП (бесплатно, оформление до ~30 дней).
   Рекомендую **личный**: команда у вас есть, 14 дней пройдут, пока мы доделываем оплату.
3. Оплатите 25 $, пройдите проверку личности (паспорт), подтвердите телефон.

## Шаг 2. Собрать приложение (PWABuilder, без программирования)

1. Откройте **pwabuilder.com**, впишите `https://mlmcrm.app`, нажмите **Start**.
2. Нажмите **Package For Stores → Android → Generate Package**, откройте **All Settings** и заполните:
   - **Package ID:** `app.mlmcrm.twa`
   - **App name:** `MLM CRM`, **Launcher name:** `MLM CRM`
   - **Start URL:** `/?app=android` ← важно: по этому адресу сайт понимает, что открыт из приложения, и прячет оплату
   - **Theme color:** `#7c3aed`, **Background color:** `#f8fafc`
   - **Signing key:** **Create new**, заполните имя и организацию (ваше ИП)
3. Нажмите **Download**. В архиве будут:
   - файл `.aab` — его загружаем в Play Console;
   - файл ключа `signing.keystore` и `signing-key-info.txt` с паролями — **сохраните оба в надёжное место (Bitwarden или зашифрованная флешка)**. Без них нельзя будет выпустить обновление приложения.
   - файл `assetlinks.json` — **его никуда загружать не нужно**, сайт сделает это сам (шаг 5).

## Шаг 3. Создать приложение в Play Console

1. **Create app** → имя `MLM CRM`, язык по умолчанию **Русский**, тип **App**, **Free**. Отметьте согласия.
2. **Test and release → Testing → Closed testing → Create track**.
3. **Testers:** создайте список с адресами Gmail ваших людей (минимум 12, лучше 15–20 с запасом).
4. **Create new release** → загрузите файл `.aab` из шага 2. Play App Signing оставьте включённым (по умолчанию). Название релиза: `1.0`.
5. Отправьте релиз на проверку. После одобрения скопируйте **ссылку для тестировщиков** и разошлите команде: каждый открывает её на телефоне, нажимает «Стать тестировщиком» и ставит приложение.
6. **Важно:** тестировщики должны реально открывать приложение эти 14 дней — Google проверяет активность.

## Шаг 4. Карточка в Play Market (Grow → Store presence → Main store listing)

1. Тексты — из файла `docs/play-store/listing.md` (короткое и полное описание на каждом языке; языки добавляются кнопкой **Manage translations**).
2. **App icon:** `docs/play-store/app-icon-512.png`.
3. **Feature graphic:** `docs/play-store/feature-graphic-ru.png` (для английского — `-en`).
4. **Скриншоты телефона:** минимум 2, лучше 4–6: «Мой день», «Касания», карточка человека, «Команда». **Только с демо-данными**, без настоящих имён и телефонов людей — это их личные данные. Могу подготовить демо-пространство для съёмки — скажите.

## Шаг 5. Связать сайт и приложение (чтобы не было адресной строки)

1. Play Console → **Test and release → App integrity → App signing**.
2. Скопируйте **SHA-256 certificate fingerprint** из блока **App signing key certificate** (и из блока **Upload key certificate** тоже).
3. Vercel → проект **meetowl-app** → **Settings → Environment Variables** → добавьте (Production):
   - `ANDROID_PACKAGE_NAME` = `app.mlmcrm.twa`
   - `ANDROID_SHA256_FINGERPRINTS` = оба отпечатка через запятую (вид `AB:CD:…`)
4. **Deployments → ⋯ → Redeploy**.
5. Откройте `https://mlmcrm.app/.well-known/assetlinks.json` — там должны появиться ваши отпечатки. Напишите мне «готово», я проверю.

## Шаг 6. Анкеты Google (Policy → App content)

| Пункт | Что ответить |
|---|---|
| **Privacy policy** | `https://mlmcrm.app/legal/privacy` |
| **App access** | «All functionality is available after free sign-up with Google or e-mail; no special access needed.» (вход для проверяющих не нужен) |
| **Ads** | No, the app has no ads |
| **Content rating** | Категория **Utility / Productivity**; насилия, азартных игр и т. п. нет; пользователи могут общаться между собой (комментарии в команде) — **Yes** |
| **Target audience** | **18+** |
| **News app** | No |
| **Financial features / Health / Government** | No |
| **Data safety** | Собирается: **имя, e-mail, телефон (по желанию), контент пользователя** (люди, заметки, задачи, файлы), **действия в приложении**. Цели: работа приложения, управление аккаунтом. **Никому не передаётся для рекламы.** Шифрование при передаче: **Yes**. Пользователь может запросить удаление: **Yes**, ссылка `https://mlmcrm.app/legal/delete-account`. Местоположение, контакты телефона, платёжные данные: **не собираются**. |
| **Delete account URL** | `https://mlmcrm.app/legal/delete-account` |

## Шаг 7. Выход в продакшн

1. Через 14 дней закрытого теста в Play Console появится **Apply for production**. Ответьте на вопросы: сколько было тестировщиков (ваша команда), что они проверяли (касания, люди, встречи), что поменяли по их отзывам.
2. После одобрения: **Production → Create new release** → тот же `.aab` → **Rollout**. Проверка обычно занимает от нескольких часов до нескольких дней.

## Про оплату в приложении (важно)

Google не разрешает продавать подписку внутри Android-приложения мимо **Google Play Billing** и даже направлять людей платить на сайт. Поэтому в приложении кнопок и ссылок на оплату нет — это уже сделано. Ваша команда пользуется бесплатно, а кто захочет подписку — оформит её на сайте сам. Если позже захотите продавать прямо в приложении — это отдельная работа (Google Play Billing, комиссия Google 15 %).

## Если что-то пошло не так

- **В приложении видна адресная строка сверху** — не связаны сайт и приложение: проверьте шаг 5 (отпечатки и Redeploy).
- **Google отклонил по «Data safety» или «App access»** — пришлите мне текст письма, поправим ответы.
